# 📚 Simple Chinese Vocabulary App

This is a **simple web application** designed specifically for students to **efficiently search for and look up Chinese vocabulary, characters, and Pinyin**.

---

## 🚀 Live Demo

You can explore and use the application here:
**[chinese-dictionary-webapp.vercel.app](https://chinese-dictionary-webapp.vercel.app/)**

---

## 💻 Local Development Setup

This project is a **React** application that utilizes **Firebase** for data management and uses **Node.js** for its development and build environment.

### Data Source

The primary vocabulary data for this application comes from:

* **Original Project**: `https://github.com/mapull/chinese-dictionary/`
* **Conversion Note**: The sample data file `src/data/dictionary_data.json` was converted from the original source's Simplified Chinese data into **Traditional Chinese** for use in this application.

### Prerequisites

* **Node.js** (required to run the project)
